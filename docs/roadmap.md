# Roadmap

| Version | Status | Highlights |
|---|---|---|
| 1.0 | released | public-source research → product model → scope → independent architecture → phase plan, every stage gated and traced |
| 2.0 | released | **observe mode** (authenticated exploration, network shapes and screenshots, all from the user's own session) and the hardening from the first full real-product run |
| next | planned | toolchain as a mandatory architecture decision; measurable budgets must name their measurement; phase paths checked at the deepest declared tree level; two-role observe sessions offered when permission unknowns are high |
| later | idea | continuous parity — re-research on a schedule; changes become new claims and stale stages |

Guardrails stay absolute in every version: public or user-owned access only, robots.txt honoured,
no copying, independent naming, and no claim about a target's internals without evidence.
