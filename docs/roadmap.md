# Roadmap

ProductForge v1 reconstructs a product from **public** sources and produces an executable,
traced build plan. Later versions widen what can be observed — always with the same evidence and
consent rules.

| Version | Theme | Highlights |
|---|---|---|
| v1.1 | Hardening | the follow-ups in `plans/v1.1/README.md` |
| V2 | Authenticated exploration | the user's own trial account, explored with consent; screen-level workflow steps |
| V3 | Network observation | the user's own sessions: observable API shapes and realtime behaviour as Tier 1 evidence |
| V4 | Media | screenshots and demo videos as sources (stored as descriptions, never assets) |
| V5 | Continuous parity | re-research on a schedule; changes become new claims and stale stages |

Guardrails stay absolute in every version: public or user-owned access only, robots.txt honoured,
no copying, independent naming, and no claim about a target's internals without evidence.
